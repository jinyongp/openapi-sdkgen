# Go 문서 검토와 후속 검증

## 완료한 범위

Go 타깃 추가로 영향을 받는 EN/KO Go 가이드, 시작 가이드, CLI 참조, 기능·호환성 표,
예제 안내, 탐색 메뉴, README/npm README, 실행 가능한 Go 예제와 플레이그라운드를
구현·리뷰했다. 구현 커밋은 `1a91723`이다. 전체 저장소의 모든 문서를 별도로 전수
개정했다는 판정은 아니며, Go 추가와 연결된 사용 경로가 검토 범위다.

기존 [W10 리뷰](../../w10-review.md), [W11 리뷰](../../w11-review.md),
[W12 전체 리뷰](../../w12-review.md)에 계약과 검토 범위가 있다.
W11에서 docs 도구 테스트 30건, 실제 WASM/ZIP, EN/KO 브라우저 설정·재진입,
Go 예제 실행과 docs 검증·빌드를 확인했다. 이 항목들은 기존 실행 증거를 재사용한다.
모든 문서의 모든 명령을 이번에 다시 실행했다는 뜻은 아니다.

## 이번에 보완한 내용

영어·한국어 Go 가이드의 선택 생성 설명에, 출력 크기와 전체 입력 분석에 필요한
메모리가 같은 비율로 줄어들지는 않는다는 점을 추가했다. 큰 명세를 비교할 때
생성 비용과 SDK 컴파일 비용을 구분하도록 안내했다.

수치 표와 개인 실행 환경은 이 내부 측정 기록에만 둔다. 공개 benchmark 수치는
프로젝트 정책에 따라 GitHub Actions의 측정과 해당 실행 링크가 필요하다.

## 실제 검증

2026-10-19에 다음 명령이 모두 종료 코드 0으로 완료됐다.

```sh
devtools run validate:docs
devtools run build:docs
```

검증 결과는 각각 `ok Documentation validation`, `ok Documentation build`였다.
새 문단은 API나 코드 예제를 변경하지 않는다. EN/KO 문단의 의미와 기존 가이드 흐름을
대조했고, 로컬 수치를 공개 문서에 넣지 않았다.
