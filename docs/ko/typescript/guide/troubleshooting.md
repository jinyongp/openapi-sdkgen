# 문제 해결

## 생성이 실패할 때

진단의 코드·위치·해결 안내를 확인하세요. OpenAPI 버전과 빠진 참조를 확인하고 필요한
스키마 확장을 제공하세요. [OpenAPI 지원](../reference/capabilities.md)과
[원격 입력](./remote-inputs.md)에 조건별 안내가 있습니다.

## 출력 파일이 충돌할 때

관리 매니페스트를 유지하고 같은 입력·옵션으로 재생성하세요. 직접 작성한 파일은 생성기가
소유하는 경로와 분리하세요. [생성 모드](./generate.md)에서 갱신 방법을 확인할 수 있습니다.

## import나 타입 검사가 실패할 때

애플리케이션의 모듈 해석 설정을 사용하세요. 컴파일한 코드를 Node ESM에서 직접 실행하면
`.js`가 붙은 진입 경로가 필요합니다. 생성에는 TypeScript가 필요하지 않으며 선택적 검사는
[지원하는 컴파일러](../reference/types.md#compiler-support)를 사용해야 합니다.

## 요청이나 스트림이 실패할 때

[클라이언트 API](../reference/client-api.md)의 타입이 있는 오류와 raw 응답을 확인하세요.
[인증·전송](./transport.md) 설정을 점검하고 취소를 전달하세요. 스트림을 끝까지 읽지 않고
중단하면 닫기 작업도 수행해야 합니다.
