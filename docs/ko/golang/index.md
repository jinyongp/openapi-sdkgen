# OpenAPI로 Go SDK 만들기

OpenAPI 3.0·3.1·3.2에서 타입이 있는 애플리케이션 소스를 생성합니다. 의존성 버전·전송·서버 수명은
사용자 Go 모듈이 관리합니다. 실행 파일로 생성할 때는 Go가 필요하지 않으며 SDK를 컴파일하고
사용하려면 Go 1.27 이상이 필요합니다.

- [첫 SDK 만들기](/ko/golang/guide/getting-started): 생성·컴파일·로컬 모의 서버 호출.
- [생성과 검증](/ko/golang/guide/generate): 관리 출력 갱신·설정·CI.
- [호출과 오류](/ko/golang/guide/client), [모델](/ko/golang/guide/models), [스트림](/ko/golang/guide/files-links-streams).
- [선택과 빌드 비용](/ko/golang/guide/selection-cost): 생성 범위·import·링커 동작.
- [예제](/ko/golang/examples/)와 [API 참조](/ko/golang/reference/).
