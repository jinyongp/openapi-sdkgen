# OpenAPI에서 Go SDK 생성하기

OpenAPI 3.0·3.1·3.2 명세에서 클라이언트, 모델과 수신 처리기를 생성합니다.
생성된 코드는 애플리케이션의 Go 모듈에서 함께 빌드합니다. Go 1.27 이상이 필요합니다.
